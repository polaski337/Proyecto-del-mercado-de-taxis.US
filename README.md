# Proyecto Sprint 8

Proyecto de analisis de datos desarrollado en Jupyter Notebook.

## Contenido

- `proyecto sprint 8.ipynb`: notebook principal del proyecto.
- `requirements.txt`: librerias necesarias para ejecutar el notebook.

## Herramientas utilizadas

- Python
- pandas
- matplotlib
- scipy
- Jupyter Notebook

## Como ejecutar

1. Clona este repositorio.
2. Crea y activa un entorno virtual.
3. Instala las dependencias:

```bash
pip install -r requirements.txt
```

4. Abre el notebook:

```bash
jupyter notebook "proyecto sprint 8.ipynb"
```

## Descripcion

El proyecto incluye carga y analisis de datos, visualizaciones y una prueba de hipotesis.
